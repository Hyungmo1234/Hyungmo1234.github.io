35살 8년차 웹 개발 경력 및 AI 엔지니어 양형모입니다.

엉덩이를 무겁게

빠르게 발전하는 AI 시대에, 어쩌면 우리가 속해있는 많은 직업은 의미가 없어질 지 모릅니다.

그럼에도 업무의 시작과 마무리는 사람이 결정하고, 그 업무의 완성도는 당사자의 끈기가 만들어냅니다.

꽤 오랜시간, 작업물에서의 묘한 불편함, 적당한 완성도를 불쾌해하며 자리를 떠나지 않았고, 그 보상은 ‘남들보다 아주 조금 더 나은 작업물’이었습니다.

저는 99.9%와 99.99%의 차이를 이해하는 사람이라고 생각합니다.

마지막 0.09%를 채우기 위한 과정에 비해 보상이 작아 보일 수 있습니다. 그럼에도 타협하지 않고, 일정이 허락하는 한 99.999%를 향해 나아갈 수 있도록 끊임없이 팀을 설득할 것입니다.

핵심 역량

  • 웹 시스템 개발·운영 8년 — 2019년부터 Java·Spring 기반 웹과 마이데이터 API 솔루션을 개발했고, 2021년부터 행정안전부·문화체육관광부·경찰청·서울시 등 공공기관 시스템의 개발·고도화·유지보수를 맡고 있습니다. 2025년부터는 PL·PM으로 프로젝트를 이끕니다.
  • 데이터 파이프라인 설계 — 공공 API 5종 이상을 RAW → CLEAN → PostgreSQL로 정제·적재하는 ETL을 직접 설계해, 서울·경기 아파트 매매 실거래 311만 건을 쌓았습니다(Prophecy).
  • 머신러닝 모델링·검증 — 시간 분할 검증으로 기준선(직전 중위가 유지)과 RF·XGBoost·LightGBM을 비교하고, 피처를 한 번에 하나씩 넣어 효과를 확인합니다. 12개월 예측 MAE를 기준선 대비 38% 줄였습니다.
  • 자동화·운영 — GitHub Actions 스케줄로 뉴스 브리핑·유튜브 숏츠·인스타그램을 매일 자동 발행하고, 실행 상태를 30분마다 모아 이 사이트에 표시합니다.
  • AI를 도구로 쓰는 개발 방식 — Cursor·LLM으로 먼저 끝까지 만들고, 결과물을 코드와 배경지식으로 다시 해부해 기록합니다.

  • Prophecy · AI 부동산 인텔리전스 플랫폼

    공공 원천 데이터만으로 아파트의 현재 가치와 3·6·12개월 가격 전망을 보여 주는 플랫폼입니다. 2026.09 시작, 비공개 저장소.

    • 국토부 실거래·K-APT 단지·청약홈·한국은행 ECOS·VWorld 입지·법제처 고시를 수집기 → RAW → CLEAN → PostgreSQL 16으로 정제·적재하는 ETL 설계
    • 서울·경기 매매 실거래 311만 건(2011-12~2026-09)·분양권 27만 건·8,632단지·청약 공고 1,102건 구축. 과거 데이터는 한 달씩 거꾸로 받는 백필 루프로 확장하고, 대용량 적재는 스트리밍으로 바꿔 메모리 부족 해결
    • 단지·월 중위가 예측을 시간 분할로 검증. 기준선 대비 MAE 3개월 −14%(7,986만 → 6,875만 원), 6개월 −22%, 12개월 −38%(1억 3,359만 → 8,267만 원)
    • 피처 버전 v89까지 거래 구조·청약 공급·금리·물가·입지·토지이용 규제를 하나씩 넣고 검증. 효과가 없거나 표본이 작은 항목은 근거를 남기고 제외
    • Spring Boot API(검색·단지 상세·고점 추적)와 React·TypeScript 웹. pg_trgm GIN 인덱스와 COUNT 없는 페이징으로 검색 지연을 줄이고, 390px 모바일 화면까지 검증
